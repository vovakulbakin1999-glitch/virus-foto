VIRUS FOTO — актуальная версия

Последние правки:
- Убрана надпись «Съёмки по людям / Каждый круг — один человек». Над кругами больше нет этого текста.
- Фоновые фотографии двигаются заметно быстрее вверх-вниз даже без скролла.
- При скролле сами фоновые фотографии продолжают меняться.
- Заголовки получили более грубую крафтовую/рваную типографику.
- Первый круг — свежая объединённая съёмка одного человека.
- Внутри первого круга фотографии собраны последовательными блоками: спортивные вместе, платье вместе, классика/интерьер вместе.
- В жанрах фотографии этого свежего человека, если они относятся к жанру, стоят первыми.
- Зелёный отмеченный человек остаётся четвёртым кругом.
- Жанры находятся отдельно ниже.
- Из галерей доступны постоянные «Назад» и «×», с возвратом на прежнее место страницы.
- Контакты и кликабельные соцсети сохранены.
- Физических дублей фотографий нет.


Дополнительные правки v3:
- В каждом жанре фотографии теперь физически разделены на последовательные блоки по людям.
- Многоколоночная раскладка больше не может визуально перемешать разных людей.
- Между людьми добавлен только ненавязчивый рваный разделитель без подписей.
- Обложки жанров показывают исходный кадр целиком через object-fit: contain; голова и лицо не режутся CSS-кропом.
- Свободное место обложки заполняется размытым фоном из того же кадра.
- Рваная типографика усилена, при этом текст остаётся читаемым.

Правки v4:
- Обложки жанров показывают фотографию целиком, без обрезки людей, головы и краёв кадра.
- На обложках отключено увеличение при наведении, которое могло визуально подрезать кадр.
- Фоновые движущиеся фотографии показываются целиком через object-fit: contain.
- Фоновая анимация теперь двигает кадр только вверх-вниз, без zoom/scale, поэтому края фото не обрезаются.
- Фоновая сцена увеличена за пределы экрана, чтобы верхний ряд не подрезался во время движения.


Правки v8:
- Полностью убраны внешние рамки/крафтовые панели вокруг блока кругов и блока «Жанры».
- Круги с людьми теперь визуально плавают сами по себе: без рамок, обводок и дополнительного кольца.
- Заголовок «Жанры» и жанровые карточки больше не находятся в рамочном контейнере.
- Жанровые обложки идут строго по две в ряд, одинакового умеренного размера.
- Обложки остаются 9:16 и показывают исходную фотографию целиком через object-fit: contain, без кропа и размытого заполнения.
- Подписи жанров больше не находятся на бежевой плашке — они визуально относятся к плавающей карточке.
- Круги и жанры получили очень лёгкое независимое движение без резких смещений.
- Фоновые фотографии продолжают мягко двигаться.
- Смена фоновых фотографий теперь не ступенчатая: прокрутка постепенно смешивает текущий и следующий набор через continuous crossfade.
- Для сглаживания колесика/тачпада добавлена инерционная интерполяция, поэтому смена не дёргается.


Правки v9:
- Кружки людей работают как горизонтальная карусель со скроллом вправо/влево и центрированием.
- Кружок ближе всего к центру плавно увеличивается; остальные уменьшаются.
- Вместе с активным кружком увеличиваются два рамочных кольца вокруг него.
- Новых людей можно добавлять в массив persons в site-data.js: карусель автоматически расширится.
- У жанров возвращены аккуратные рамки.
- Удалена служебная фраза «Жанры находятся отдельно от кругов».
- Фоновые фото сделаны крупнее, а скролл-переходы между ними — более длинными и плавными.
- Рваная типографика теперь строится на выщербленных/неровных краях вместо полос-перечёркиваний.
